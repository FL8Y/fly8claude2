# FLY8 Clone logo assets

These SVGs are the canonical vector exports for the current FLY8 Clone identity.

- `FLY8_Clone_Logo.svg` — 1024×1024 presentation layout: white canvas, dark rounded-square tile, centered mark.
- `FLY8_Clone_Launcher.svg` — 1024×1024 full-bleed launcher artwork.
- `FLY8_Clone_Adaptive_Foreground.svg` — transparent color foreground; the two negative-space channels remain transparent.
- `FLY8_Clone_Adaptive_Background.svg` — background-only dark navy/black layer.
- `FLY8_Clone_Adaptive_Monochrome.svg` — one-color themed-icon foreground with transparent channels.

## Design intent

The logo is one asymmetric cyan-blue mass with two broad, offset negative-space lanes. A shared pointed source resolves into two independent right-facing channels. The two dark slots are real even-odd cutouts in the SVG, not black rectangles pasted over the mark. This keeps the silhouette integrated and avoids stacked app cards, a literal eye/camera, a stock infinity mark, thin network-node diagrams, UI window controls, or decorative cyberpunk effects.

The established FLY8 palette is used: near-black `#000001`, surfaces `#010205` / `#01132A`, primary blue `#176E94`, deep blue `#01304C`, and light accent `#FCFDFD`.

## Validation status

The local artifact set includes a 1024px presentation render, a full-bleed launcher render, actual 24px / 32px / 48px downscales, grayscale and one-color silhouette previews, and circle / rounded-square mask previews. These are visual design checks, not a substitute for installing the icon in the target Android launcher. No independent user study or formal trademark clearance is claimed.
