PART 4. THE NEW STRUCTURE FOR EVERY DISEASE / CONDITION NOTE
---------------------------------------------------------------------
Rewrite the "body" of each disease, disorder or clinical-problem note into EXACTLY these sections,
in this order. Use plain, exam-ready wording. Short bullets. Philippine context everywhere it applies.

## What it is
  1-3 sentences: definition, who gets it, why it matters on the PNLE.

## Causative agent
  The organism (genus/species, type: virus/bacteria/parasite/fungus), or the cause/risk factors
  if not infectious (e.g. autoimmune, genetic, trauma). Include mode of transmission, incubation
  period and period of communicability for communicable diseases. Include the vector or reservoir
  common in the Philippines (e.g. Aedes aegypti, Anopheles flavirostris, Oncomelania snail).
  If there is no causative agent (e.g. a nursing concept), write "Not applicable" and the main risk factors.

## Main problem
  The core pathophysiology in 1-3 sentences: what goes wrong in the body (the "why" behind the signs).

## Initial manifestations
  The EARLY / first signs and symptoms (what the nurse sees first). Mark pathognomonic signs with
  "(pathognomonic)" only if a reference supports it.

## Other manifestations
  Later, severe or complicating signs; warning signs; danger signs that need referral.

## Laboratory and diagnostic data
  Key tests and the expected abnormal result (with normal ranges ONLY when a reference gives them,
  in SI or conventional units as used in the Philippines). Confirmatory test vs screening test.

## Nursing diagnoses
  2-5 priority nursing diagnoses in NANDA-I style (problem related to cause as evidenced by signs),
  ordered by priority (ABC, Maslow, safety). Mark the top one "(priority)".

## Nursing interventions
  Numbered, in priority order. Each line: the action, then " - " and a short rationale.
  Include: assessment first, safety, infection control/isolation type, positioning, fluids/nutrition,
  medications by CLASS (drug names only if the reference names them; DOSES ONLY if a cited
  reference states the dose, otherwise write "dose per physician order / current guideline"),
  health teaching, referral, and prevention.

## Philippine context
  DOH program or strategy that covers it (e.g. EPI, National TB Program DOTS, Dengue Prevention and
  Control Program, Rabies Prevention and Control Program, Integrated Management of Childhood Illness),
  relevant Republic Act or DOH Administrative Order (number + name, only if verified),
  local terms (Filipino names, e.g. "bulutong", "tigdas"), common local exam traps.

## Exam traps
  3-5 bullets: classic PNLE-style confusions and the correct thinking (e.g. "fever falls in the
  critical phase of dengue = danger, not improvement").

## Related topics
  Keep the existing [[Wikilinks]]; add only links to notes that exist.

## References
  2-5 numbered references you ACTUALLY opened and read. Format:
  1. Organization or author. Title. Year (or "accessed YYYY-MM-DD"). URL
  Each key fact you added must be supported by at least one reference in this list.

## Check against your textbook
  Keep the existing text, then add any fact you could NOT verify, written as
  "UNVERIFIED: ..." so the owner can check it in their textbook.

For NON-disease notes (programs, laws, concepts, procedures, growth and development stages,
therapeutic communication, etc.): do NOT force the disease sections. Use only the sections that
make sense (always keep "What it is", add "Philippine context", "Exam traps", "References",
"Check against your textbook"). Say in your batch notes which notes you treated as non-disease.

     clinical practice guidelines, disease fact sheets), DOH Epidemiology Bureau.
  2. Official Philippine law and issuances: https://www.officialgazette.gov.ph , https://lawphil.net
     (Republic Acts, e.g. RA 9173 Philippine Nursing Act of 2002; verify every RA number).
  3. Professional Regulation Commission (PRC): https://www.prc.gov.ph (PNLE scope / table of
     specifications if available).
  4. WHO and WHO Western Pacific Region: https://www.who.int , https://www.who.int/westernpacific
  5. Philippine medical societies' public guidelines (e.g. Philippine Society for Microbiology and
     Infectious Diseases, Philippine Pediatric Society, Philippine Heart Association), PhilHealth.
  6. US CDC / NIH MedlinePlus / StatPearls (NCBI Bookshelf) for pathophysiology and lab data.
  7. NANDA-I terminology for nursing diagnoses (name the diagnosis; do not paste copyrighted definitions).

Search queries you should use (adapt per topic):
  "<disease> DOH Philippines", "<disease> clinical practice guideline Philippines",
  "<disease> administrative order DOH", "<disease> WHO fact sheet", "<disease> StatPearls",
  "<program name> DOH manual of operations", "Republic Act <number> <title> lawphil".

Verification rules:
- Open every source you cite and confirm the fact is on that page. Never cite a page you did not open.
- Never invent a URL, a law number, a guideline year, a page number, an author, or a drug dose.
- If two good sources disagree, state both and which is current (newest DOH guidance wins for PH practice).
- If the existing note contains a fact that your sources contradict, FIX it and list the fix in your
  batch notes as "CORRECTED: old -> new (source #)".
- If you cannot verify something, keep it out of the main sections and put it under
  "Check against your textbook" as UNVERIFIED.
- Write in your own words. Do not copy paragraphs from sources or textbooks. Short facts and
  official names/terms are fine.
- NEVER use, copy or reconstruct real PNLE board questions or "recalled questions" sites.
  They are confidential/copyrighted. Do not write any test questions in this mission.
- No patient-specific medical advice. This is exam review content.
