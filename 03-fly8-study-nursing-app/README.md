# FLY8 Study: project resources

Personal PNLE nursing study app (Expo / React Native + TypeScript, Android-first, local-first).

- `app/` the app source (the code, 700+ original practice questions, 974 AI-written study notes). Start with `app/docs/MASTER_PLAN.md` and `app/HANDOFF.md`.
- `planning/` master plan, requirements, decision log, authoring kit, prompt maker kit, agent instructions (`CLAUDE.md`).
- `inspo-and-research/` reference research on other apps (Tangerine Prep, Gizmo, AnkiDroid and others). Ideas and flow only; never copy their code, art, brand or question content. Kept separate on purpose.

Left out on purpose: the owner's review-handout PDFs and their extracted text, `node_modules`, API keys, local databases.
All questions and notes are AI-written and not nurse-reviewed. Nothing has been run on a phone.
Source of truth for history: https://github.com/FL8Y/readthischatgpt (branch ccr-13ebab09-xygfde, PR #7).
