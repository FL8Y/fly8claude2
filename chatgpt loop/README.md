## Operating rule
Improve only files inside this `chatgpt loop/` directory. Each iteration must identify a concrete defect or measurable improvement, make a narrow change, run relevant checks, and record evidence. Stop when the exit criteria are met or when another pass would not materially improve correctness, safety, usability, or verifiability. Never simulate infinite work or claim a test was run when it was not.

## Safety
This is research assistance, not an autonomous bedside nurse, clinical authority, legal authority, or ethics committee. Do not put identifiable patient information in this workspace.
